# Эмбеддинги и семантический поиск — Блок 5.1

## Выбор embedding-модели

### Анализ предметной области

| Параметр | Значение |
|----------|----------|
| Язык документов | Русский (юридические и технические тексты ФТС) |
| Характер текстов | Приказы, классификаторы, руководства программиста, заявки на развитие |
| Объём корпуса | 50+ документов, средний размер ~2000 токенов |
| Конфиденциальность | **Только локально (self-hosted)** — запрет передачи данных во внешние API |
| Типичная длина запроса | 10–40 слов (русский) |

### Критерии выбора

1. **Self-hosted обязательно** — никакие данные не покидают контур организации. OpenAI, Voyage, Cohere — исключены.
2. **Русский язык** — основной. Модель должна показывать высокие результаты на ruMTEB (Retrieval).
3. **Размерность**: 1024 — оптимум между качеством поиска и затратами на хранение векторов.
4. **Длина контекста**: ≥ 512 токенов для покрытия смысловых блоков документов.
5. **Простота развёртывания**: работает на CPU (не требует GPU), запускается через sentence-transformers.

### Сравнение локальных кандидатов

| Модель | Размерность | Max токенов | Русский (ruMTEB) | Размер | E5-префиксы |
|--------|-------------|-------------|-------------------|--------|-------------|
| `intfloat/multilingual-e5-large` | 1024 | 512 | **Лидер** (Retrieval) | 1.1 GB | Да (`query:`/`passage:`) |
| `BAAI/bge-m3` | 1024 | 8192 | Хорошо | 2.2 GB | Нет |
| `intfloat/multilingual-e5-base` | 768 | 512 | Хорошо | 0.5 GB | Да (`query:`/`passage:`) |
| `ai-forever/FRIDA` | 768 | 512 | Отлично (только RU) | 1.3 GB | Нет |

### Рекомендация: `intfloat/multilingual-e5-large`

Обоснование:

- **Лучшая поддержка русского языка** среди open-source моделей (лидер ruMTEB в категории Retrieval)
- **Self-hosted** — все вызовы локальны, данные не покидают сервер. Полное соответствие требованию конфиденциальности
- **Нулевая стоимость инференса** — после загрузки модели API-ключи не нужны, нет лимитов на запросы
- **E5-семейство** — требует префиксов `query:` / `passage:`, что уже реализовано в `EmbeddingsService.embed_query()` / `embed_documents()`. Без префиксов качество retrieval падает на 5–10 пунктов
- **Размерность 1024** — хороший баланс:
  - Память на индекс: 50 000 чанков × 1024 × 4 байта ≈ 205 МБ
  - Для сравнения: FRIDA (768) ≈ 154 МБ, bge-m3 (1024) ≈ 205 МБ
- **Работает на CPU**: приемлемая скорость инференса (16–32 текстов в батче)

### Расчёт стоимости индексации (локальная модель)

```
Модель: intfloat/multilingual-e5-large
Инфраструктура: CPU (без GPU)
Параметры:
- Документов: 50
- Средний размер документа: 2000 токенов
- Чанков на документ: ~5 (при размере чанка ~400 токенов)
- Итого эмбеддингов: 50 × 5 = 250 векторов

Время индексации:
- Батч 32 текста, ~0.5 сек на батч (CPU)
- 250 / 32 ≈ 8 батчей × 0.5 сек ≈ 4 секунды

Память:
- Сама модель в RAM: ~1.1 GB
- Векторный индекс (250 × 1024 × 4 байта): ~1 МБ

Стоимость: $0 (электричество на CPU не учитываем)

Масштабирование на 500 документов:
- 500 × 5 = 2500 векторов
- 2500 / 32 ≈ 79 батчей × 0.5 сек ≈ 40 секунд
- Индекс: ~10 МБ
```

## Кеширование

Реализовано в `EmbeddingsService` (`app/services/embeddings.py`):

- **In-memory кеш**: FIFO-подобный, до 10 000 записей. Ключ = `sha256(model:dimensions:text)`.
- **Дисковый кеш (diskcache)**: опционально, через параметр `cache_dir`. Сохраняет векторы между рестартами.
- **Инвалидация**: при смене модели или размерности ключи меняются автоматически.
- **Проверка**: повторный вызов `embed_texts(["тот же текст"])` не вызывает модель повторно — `cache_stats()` покажет hits > 0.

## Smoke-тест

```bash
# Проверка работы EmbeddingsService с кешированием
uv run python -c "
import asyncio
from app.services.embeddings import create_embeddings_service

async def test():
    svc = create_embeddings_service(
        provider='sentence_transformers',
        model='all-MiniLM-L6-v2',
    )
    # Первый вызов
    v1 = await svc.embed_texts(['тестовый текст', 'другой текст'])
    print(f'Размерность: {len(v1[0])}')

    # Повторный вызов — должен попасть в кеш
    v2 = await svc.embed_texts(['тестовый текст', 'другой текст'])
    stats = svc.cache_stats()
    print(f'Статистика: {stats}')
    assert stats['hits'] == 2, f'Expected 2 hits, got {stats[\"hits\"]}'
    assert stats['misses'] == 2, f'Expected 2 misses, got {stats[\"misses\"]}'
    print('Cache OK!')

    # Проверка нормализации
    import math
    norm = math.sqrt(sum(x*x for x in v1[0]))
    print(f'Vector norm: {norm:.6f} (should be ~1.0)')
    assert abs(norm - 1.0) < 0.001, 'Vector not normalized!'

asyncio.run(test())
"
```
