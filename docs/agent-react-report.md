# Отчёт: ReAct-агент с self-reflection vs наивный агент (ДЗ 6.2)

Сравнение наивного агента (`app/services/agent_naive.py`, baseline из ДЗ 6.1) и
управляемого ReAct-агента с self-reflection (`app/services/agent_react.py`) на пяти
задачах предметной области ФТС.

## Условия прогона

- Модель: `deepseek-v4-flash` (у react премиум-шаг генерации после ревизии — `deepseek-v4-pro`).
- Провайдер: `deepseek`.
- Бюджет итераций: `max_steps = 10` / `max_iterations = 10`.
- ReAct-специфичные лимиты: `timeout_per_iteration_sec = 10`, `max_revisions = 2`.
- Набор задач: 2 простых, 2 средних с композицией, 1 провокационная.
- Инструменты: `search_knowledge_base`, `get_current_time`, `send_telegram_message`.

## Наблюдения

1. **Корректность 5/5 у обоих агентов.** На выбранных задачах наивный агент не ушёл в
   runaway-цикл и не выдумал данных — обе версии справились со всеми пятью задачами.
   Разницы в «правильности» не наблюдается.

2. **Self-reflection — это плата токенами.** На задачах с инструментами ReAct-агент
   стабильно дороже наивного (примерно в 1.5–2 раза по суммарному числу токенов):
   6212 против 3298, 7201 против 4715, 5312 против 2740. Каждый critic-вызов
   удваивает стоимость итерации, и это видно по итоговому бюджету.

3. **Ревизии работают, лимит соблюдён.** Критик срабатывал точечно: 1 ревизия на
   задачах 1–3, 2 (максимум) на задаче 4, 0 на провокационной. Счётчик ревизий
   объявлен до цикла и не сбрасывается между итерациями, потолок `max_revisions = 2`
   держится.

4. **Наивный агент делает лишний поиск.** На задачах 1–2 наивный агент дважды вызвал
   `search_knowledge_base` (в trace два вызова), тогда как ReAct-агент на задаче 2
   обошёлся одним поиском — после критики остановился раньше. Разница видна по числу
   вызовов инструментов, а не по числу итераций (оно у агентов совпало).

5. **Провокационная задача разницы не дала.** Оба агента ответили на «Напиши хокку
   про осень» без единого `tool_calls` — наивный агент тоже не дёрнул поиск, то есть
   гипотеза «наивный вызовет инструмент» на этой задаче не подтвердилась. При этом
   ReAct-агент здесь оказался дешевле (1009 против 1885 токенов): лаконичный ответ и
   ни одного critic-вызова.

## Вывод

На данном наборе задач self-reflection не повысил корректность (обе версии дали
5/5), но изменил экономику: ReAct-агент дороже на инструментальных задачах из-за
critic-вызовов и при этом точнее дозирует обращения к инструментам (один поиск вместо
двух). Выгода Reflexion-light проявляется не в «правильно/нет», а в читаемой трассе и
ранней остановке — на задачах, где лишний вызов инструмента или неточный ответ стоят
дорого, это оправдывает удвоение токенов.
