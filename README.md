# IntelliBase
Корпоративная база знаний с использованием ИИ.

# Тема
Ассистент для анализа документов.
# Описание
Cистематизирует и предоставляет инструменты поиска и анализа внутренней документации (форматы pdf, docx, ...) для сотрудников IT-компании.

# Быстрый старт

Требуется Docker с плагином compose.

```bash
cp .env.example .env      # заполнить токены (BOT_TOKEN, ключи LLM)
make up                   # поднять стек: app + bot + Postgres + Redis + Qdrant + Phoenix
make smoke                # проверить, что система жива и отвечает
```

Первый запуск занимает несколько минут: приложение скачивает embedding-модель (~2 ГБ)
и индексирует демонстрационный корпус из `data/demo_kb` (18 синтетических документов
в репозитории — реальные документы для старта не нужны). Рабочий корпус подключается
через `RAG_DATA_DIR` в `.env`. Сервисы:

| Сервис | Адрес |
|---|---|
| API (FastAPI) | http://localhost:8000 — `/health`, `/ready`, `/docs` |
| Phoenix (трейсы) | http://localhost:6006 |
| Qdrant | http://localhost:6333 |
| Telegram-бот | отдельный процесс в compose |

Остальные команды — `make help`; индексация, тесты и оценка качества —
[docs/runbook.md](docs/runbook.md).
